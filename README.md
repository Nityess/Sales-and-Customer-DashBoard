# Tableau Dashboard Project

## Overview
This project contains mockups and designs for a Tableau dashboard that shows sales performance data.

## Dashboard Features

### Main Dashboard
The dashboard displays key business metrics in an easy-to-read format:

**Key Performance Indicators (KPIs):**
- **Sales**: $30K total sales
- **Profit**: $25K total profit  
- **Quantity**: 60K items sold

**Visual Charts:**
- **Top Category**: Horizontal bar chart showing the best-performing product categories
- **Sales vs Profit**: Line chart comparing sales and profit trends over time
- **Sales by Category**: Pie chart breaking down sales by different product categories

### Dashboard Layout Structure

The dashboard uses a container-based layout system:

**Main Container (Vertical)**
- **Title Section**: Displays the dashboard title at the top
- **Content Area**: Split into two horizontal sections
  - **Top Section**: Contains three KPI boxes (BANs - Big Ass Numbers)
  - **Bottom Section**: Contains charts and visualizations
    - Left side: Single large chart
    - Right side: Two smaller charts stacked vertically

## Container Types

The dashboard uses three types of containers:

1. **Vertical Container (Main)**: The overall structure that holds everything
2. **Horizontal Container (BANs)**: Holds the three KPI boxes side by side
3. **Horizontal Container (Charts)**: Holds the chart visualizations
4. **Vertical Container (Charts)**: Stacks charts on top of each other

## Purpose

This dashboard helps business users quickly see:
- How much money the company is making (sales and profit)
- How many items are being sold
- Which product categories are performing best
- Trends in sales and profit over time
- How sales are distributed across different categories

## Usage

This mockup can be used as a reference when building actual Tableau dashboards. The simple layout makes it easy for users to find the information they need quickly.
